## 🆘 **TROUBLESHOOTING**

### Can't connect to http://localhost:8501?
```
1. Check if Streamlit is running (port 8501)
2. Refresh browser (Ctrl+F5)
3. Check terminal for errors
4. Restart services
```

### Backend not responding?
```
1. Check if backend running (port 8000)
2. Test: http://localhost:8000/health
3. Check .env file
4. Restart both services
```

### Chat not returning responses?
```
1. Check internet connection
2. Verify API keys in .env
3. Check backend logs
4. Demo mode should always work
```

### Documents not uploading?
```
1. Check file format (PDF, TXT, MD, DOCX)
2. Check file size (< 10MB recommended)
3. Verify permissions
4. Try different file
```
